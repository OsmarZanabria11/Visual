💻 Programación Visual

Temas, subtemas, actividades y recursos de la asignatura

Bienvenidos

En este sitio encontrarás los temas y subtemas de la asignatura Programación Visual. Cada tema presenta su estructura temática para facilitar la consulta de contenidos, actividades, ejercicios, prácticas y recursos que se incorporarán conforme avance el curso.

📚 Temas de la asignatura

🖥️
Tema 1

Interfaces gráficas de usuario

Fundamentos de programación orientada a objetos, interfaces gráficas y programación visual orientada a eventos.

  1. 1.1. Fundamentos de programación orientada a objetos.
  2. 1.2. Introducción a la programación de interfaces gráficas de usuario.
  3. 1.3. Lenguajes de programación para el desarrollo de interfaces gráficas de usuario.
  4. 1.4. Introducción a la programación visual orientada a eventos.
🧩
Tema 2

Elementos básicos de las interfaces gráficas de usuario

Desarrollo de interfaces gráficas utilizando objetos básicos y diseño de aplicaciones visuales.

  1. 2.1. Introducción al desarrollo de interfaces gráficas de usuario.
  2. 2.2. Aplicación de objetos básicos:
  3. 2.2.1. Para manejo de texto.
  4. 2.2.2. Botones.
  5. 2.2.3. Barras de desplazamiento.
  6. 2.2.4. Listas desplegables.
  7. 2.2.5. Cajas de verificación.
  8. 2.2.6. Cuadro de imágenes.
  9. 2.3. Diseño de interfaces utilizando objetos básicos.
⚙️
Tema 3

Elementos avanzados de las interfaces gráficas de usuario

Aplicación de objetos avanzados, organización de datos y herramientas para el desarrollo de interfaces gráficas.

  1. 3.1. Aplicación de objetos avanzados.
  2. 3.1.1. Menús.
  3. 3.1.2. Cajas de diálogo.
  4. 3.1.3. Controles de rango.
  5. 3.1.4. Temporizadores.
  6. 3.1.5. Barras de progreso.
  7. 3.1.6. Cuadros de dialogo predefinidos.
  8. 3.1.7. Otros.
  9. 3.2. Diseño de interfaces gráficas de usuario utilizando objetos avanzados.
  10. 3.3. Organización y visualización de datos.
  11. 3.4. Asistentes para el desarrollo de interfaces.
🔌
Tema 4

Desarrollo de interfaces gráficas de usuario aplicadas a puertos

Programación de puertos mediante interfaces visuales y desarrollo de aplicaciones con conectividad.

  1. 4.1. Introducción a la programación de puertos con interfaces visuales.
  2. 4.2. Desarrollo de aplicaciones con interfaces gráficas de usuario con conectividad a puertos seriales y/o paralelo.
📊
Tema 5

Desarrollo de aplicaciones

Aplicaciones de interfaces gráficas para adquisición de datos, sistemas de control, procesos locales y remotos y bases de datos.

  1. 5.1. Desarrollo de aplicaciones de interfaces gráficas en la adquisición de datos digitales y analógicos.
  2. 5.2. Desarrollo de interfaces gráficas aplicadas a sistemas de control.
  3. 5.3. Desarrollo de aplicaciones de interfaces gráficas de usuario aplicadas proceso locales y remotos.
  4. 5.4. Manejo básico de base de datos con aplicación a sistemas electrónicos.
