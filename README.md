# Programación Visual

Repositorio de actividades académicas para Ingeniería Electrónica del ITSAO.

## Publicar con GitHub Pages

1. Crear/publicar este repositorio en GitHub.
2. Ir a **Settings → Pages**.
3. Seleccionar **Deploy from a branch**.
4. Elegir la rama `main`.
5. Elegir `/(root)`.
6. Guardar.

La página tendrá una dirección similar a:

`https://OsmarZanabria.github.io/Programacion-Visual/`
